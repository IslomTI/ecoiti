Модуль А (Аудит)

**Время:** 4 часа **Задача:** Написать отчет в формате `.odt`.

---

## 1. 📝 Алгоритм работы (The Loop)

1. **Открой Оценочный лист (Marking Scheme).** Читаешь пункт 1 (например: *"На rtr-cod настроен IP 178.207.179.4"*).
2. **Зайди на устройство.**
3. **Введи команду проверки.** (например, `show ip interface brief` или `ip a`).
4. **Сделай скриншот.**
* На скрине должно быть видно: **Имя хоста**, **Команду**, **Результат**.
* Используй `Spectacle` или `Flameshot` (что будет в системе).


5. **Запиши в отчет:**
* **Статус:** ВЫПОЛНЕНО / НЕ ВЫПОЛНЕНО / ЧАСТИЧНО.
* **Комментарий:** *"IP-адрес настроен верно согласно топологии"* или *"Настроен неверный IP 10.0.0.1"*.
* **Вставь скриншот.**



---

## 2. 🐧 Alt Linux (Серверы и Свитчи)

В Модуле А часто используют **NetworkManager**, так что проверяй и через него, и через `/etc/net`.

### 🌐 Сеть

* **Все адреса:** `ip -c a` (Скриншоть это первым делом).
* **Шлюз и маршруты:** `ip -c r`.
* **VLAN и Мосты:** `bridge link` или `ip -d link show`.
* **DNS (куда смотрит):** `cat /etc/resolv.conf`.
* **Открытые порты:** `ss -tulpn` (Важно для проверки сервисов!).

### 🛠️ Сервисы (Systemd)

* **Статус службы:** `systemctl status <service_name> --no-pager -l`
* *Зеленое (active)* — работает.
* *Красное (failed)* — сломано (скриншоть ошибку!).
* *Серые (inactive)* — не запущено.


* **Список всех служб:** `systemctl list-units --type=service --state=active`.

### 📂 Файлы и Диски

* **Место на диске:** `df -hT`.
* **Разделы и RAID:** `lsblk` или `cat /proc/mdstat`.
* **Примонтированное (NFS/CIFS):** `mount | grep nfs`.
* **Fstab (автозагрузка):** `cat /etc/fstab`.

### 👥 Пользователи

* **Список юзеров:** `cat /etc/passwd | grep sh` (покажет живых людей).
* **Группы:** `id <username>` или `cat /etc/group`.

### 🔥 Логи (Если нужно найти ошибку)

* `journalctl -xe` — последние ошибки системы.
* `/var/log/messages` или `/var/log/syslog`.

---

## 3. 🟢 EcoRouter (Cisco-like)

Команды почти как в Cisco.

### 🌐 Интерфейсы и L2

* **Краткая сводка:** `show ip interface brief` (Мастхэв!).
* **Подробно:** `show interface gigabitethernet 0/0`.
* **VLAN:** `show vlan`.

### 🛣️ Маршрутизация

* **Таблица маршрутов:** `show ip route`.
* **OSPF Соседи:** `show ip ospf neighbor`.
* **OSPF Настройки:** `show ip ospf interface`.
* **BGP Соседи:** `show ip bgp summary`.

### ⚙️ Конфиг

* **Текущий конфиг:** `show running-config` (Можно листать пробелом).
* *Совет:* `show run | include <слово>` (фильтр).



---

## 4. 🧱 Проверка конкретных сервисов

### 🌍 DNS (Bind)

* **Проверка зоны:** `dig @127.0.0.1 cod.ssa2026.region ANY`.
* **Проверка конфига:** `named-checkconf`.
* **Проверка файла зоны:** `named-checkzone cod.ssa2026.region /var/lib/bind/...`.

### ☁️ Active Directory (Samba)

* **Проверка домена:** `samba-tool domain level show`.
* **Список юзеров:** `samba-tool user list`.
* **Тест DNS:** `host -t SRV _ldap._tcp.office.ssa2026.region`.
* **Тест входа:** `smbclient -L localhost -U%`.

### 🗄️ iSCSI

* **Target (Сервер):** `targetcli ls`.
* **Initiator (Клиент):** `iscsiadm -m session`.

### 🐘 Базы Данных (PostgreSQL)

* **Вход:** `psql -U postgres`.
* **Список баз:** `\l`.
* **Список таблиц:** `\dt`.
* **Пользователи:** `\du`.

* *"Служба находится в состоянии failed (см. скриншот)."*
* *"Отсутствует необходимый пакет/конфигурационный файл."*
* *"Неверный IP-адрес на интерфейсе (ожидалось: ..., фактически: ...)."*
* *"Связность отсутствует, маршрут по умолчанию не задан."*
* *"В конфигурации firewall отсутствует разрешающее правило."*
