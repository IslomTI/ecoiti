### 📄 File: `ansible.cfg`

Конфигурация для отключения проверок (экономит время).

```ini
[defaults]
# Путь к инвентарю
inventory = ./hosts
# Отключение проверки SSH Host Key (критично для скорости)
host_key_checking = False
# Пользователь по умолчанию на удаленных машинах
remote_user = root
# Отключение предупреждений
deprecation_warnings = False
# Логирование (опционально, если требуют)
log_path = ./ansible.log

```

### 📄 File: `hosts`

Инвентарь (список серверов).

```ini
[webservers]
srv1-cod ansible_host=192.168.10.10

[dbservers]
srv2-cod ansible_host=192.168.10.20

[storage]
srv3-backup ansible_host=192.168.10.30

[all:vars]
# Если ключи не сработали, Ansible будет использовать этот пароль
ansible_ssh_pass=P@ssw0rd
# Принудительно используем Python 3
ansible_python_interpreter=/usr/bin/python3

```

## 📜 3. Ansible Playbook (`site.yml`)

Основной сценарий настройки.
**Важно:** Используем модуль `package` (универсальный для Alt Linux/Debian) и `handlers` (для правильного перезапуска).

```yaml
---
- name: Configure Common Settings for ALL Servers
  hosts: all
  become: yes
  tasks:
    - name: Ensure minimal tools are installed
      package:
        name: "{{ item }}"
        state: present
      loop:
        - curl
        - vim
        - htop

    - name: Create Administrator User
      user:
        name: ws_admin
        shell: /bin/bash
        groups: wheel
        # Пароль 'P@ssw0rd' (захешированный sha512)
        password: "$6$rounds=656000$gK5.3/X.1$Z7.Q.K.G.s.t.u.v.w.x.y.z...GENERATE_YOUR_OWN_HASH_OR_USE_PLAINTEXT_IF_ALLOWED"
        generate_ssh_key: yes

- name: Configure Web Servers (Nginx)
  hosts: webservers
  become: yes
  tasks:
    - name: Install Nginx
      package:
        name: nginx
        state: present
      notify: Restart Nginx

    - name: Enable Nginx service
      service:
        name: nginx
        state: started
        enabled: yes

    - name: Deploy Custom Index Page
      copy:
        dest: /var/www/html/index.html
        content: |
          <html>
            <head><title>WS-2026</title></head>
            <body><h1>Welcome to Automation Module</h1></body>
          </html>
        mode: '0644'

  handlers:
    - name: Restart Nginx
      service:
        name: nginx
        state: restarted

- name: Configure Database Servers (PostgreSQL)
  hosts: dbservers
  become: yes
  tasks:
    - name: Install PostgreSQL
      package:
        name: postgresql14-server  # В Alt Linux имя может быть с версией! Проверь через apt-cache search
        state: present
      # Если package не находит, используй generic 'postgresql' или shell

    - name: Initialize DB (Alt Linux specific)
      shell: /etc/init.d/postgresql initdb
      args:
        creates: /var/lib/pgsql/data/PG_VERSION # Не запускать, если база уже есть

    - name: Start and Enable PostgreSQL
      service:
        name: postgresql
        state: started
        enabled: yes

    - name: Create App Database
      become_user: postgres
      postgresql_db:
        name: app_db
        state: present
      # Требует пакет python3-module-psycopg2 на удаленном хосте!
      # Если его нет, используй: shell: psql -c "CREATE DATABASE app_db;"

```

## 🐍 4. Python Audit Script (`audit.py`)

Скрипт для сбора метрик. Не использует `psutil`, чтобы работать на любой "чистой" машине.

```python
#!/usr/bin/python3
import os
import subprocess
import datetime
import socket

# Настройки
OUTPUT_DIR = "/var/log/audit_reports"
DATE_STR = datetime.datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
FILENAME = f"{OUTPUT_DIR}/report_{DATE_STR}.txt"

def get_cmd_output(command):
    try:
        return subprocess.check_output(command, shell=True).decode('utf-8').strip()
    except Exception as e:
        return str(e)

def collect_info():
    # 1. Hostname & IP
    hostname = socket.gethostname()
    ip_addr = get_cmd_output("hostname -I | awk '{print $1}'")
    
    # 2. CPU Load (Load Average 1 min)
    cpu_load = get_cmd_output("uptime | awk -F'load average:' '{ print $2 }' | cut -d, -f1")
    
    # 3. Free Memory (MB)
    mem_free = get_cmd_output("free -m | grep Mem | awk '{print $4}'")
    
    # 4. Disk Usage (Root partition)
    disk_usage = get_cmd_output("df -h / | tail -1 | awk '{print $5}'")

    report = f"""
    ========================================
    SERVER AUDIT REPORT
    ========================================
    Date:       {datetime.datetime.now()}
    Hostname:   {hostname}
    IP Address: {ip_addr}
    ----------------------------------------
    CPU Load:   {cpu_load.strip()}
    Free RAM:   {mem_free} MB
    Disk Usage: {disk_usage} used
    ========================================
    """
    return report

if __name__ == "__main__":
    # Создаем папку, если нет
    if not os.path.exists(OUTPUT_DIR):
        os.makedirs(OUTPUT_DIR)
        
    # Записываем отчет
    data = collect_info()
    with open(FILENAME, "w") as f:
        f.write(data)
    
    print(f"[OK] Report saved to {FILENAME}")

```

## 🐚 5. Bash Backup Script (`backup.sh`)

Скрипт резервного копирования с ротацией (удалением старых копий).

```bash
#!/bin/bash

# --- CONFIG ---
SOURCE_DIRS="/etc /var/www/html"   # Что бэкапим
BACKUP_ROOT="/var/backups/sys_backup"
DATE=$(date +%Y-%m-%d)
BACKUP_FILE="$BACKUP_ROOT/backup_$DATE.tar.gz"
RETENTION_DAYS=7                   # Сколько дней хранить
LOG_FILE="/var/log/backup_script.log"

# --- LOGGING FUNCTION ---
log_msg() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $1" >> $LOG_FILE
}

# 1. Создание директории
mkdir -p $BACKUP_ROOT

# 2. Создание архива
log_msg "Starting backup of $SOURCE_DIRS..."
tar -czf $BACKUP_FILE $SOURCE_DIRS 2>/dev/null

# 3. Проверка статуса
if [ $? -eq 0 ]; then
    log_msg "SUCCESS: Archive created at $BACKUP_FILE"
else
    log_msg "ERROR: Backup failed!"
    exit 1
fi

# 4. Ротация (Удаление файлов старше 7 дней)
log_msg "Cleaning up old backups (older than $RETENTION_DAYS days)..."
find $BACKUP_ROOT -name "backup_*.tar.gz" -mtime +$RETENTION_DAYS -delete

log_msg "Backup procedure completed."

```

## ⏰ 6. Cron Scheduling

Как добавить задачи в планировщик.

1. Открой крон: `crontab -e`
2. Вставь следующие строки:

```bash
# === Automation Tasks ===

# 1. Запускать мониторинг (Python) каждые 15 минут
*/15 * * * * /usr/bin/python3 /root/ansible_project/audit.py

# 2. Запускать бэкап (Bash) каждый день в 02:30 ночи
30 02 * * * /bin/bash /root/ansible_project/backup.sh

# 3. (Опционально) Ansible Pull/Run для поддержания конфига каждые 30 мин
*/30 * * * * ansible-playbook /root/ansible_project/site.yml >> /var/log/ansible_cron.log 2>&1

```
